Where this data comes from

/dynamic_joint_states

The server forwards every state interface by name and interprets none of them — thresholds, staleness, panel layout and the status table all live in config.js, next to this page.

Temperature and status stay empty until openarm_hardware exports those interfaces. The values already exist in Motor::get_state_tmos(); they stop at export_state_interfaces(), which returns only position, velocity and effort.

# add to openarm_simple_hardware.cpp — nothing else has to change
state_interfaces.emplace_back(hardware_interface::StateInterface(
    joint_names_[i], "temperature_mos",   &tmos_states_[i]));
state_interfaces.emplace_back(hardware_interface::StateInterface(
    joint_names_[i], "temperature_rotor", &trotor_states_[i]));
state_interfaces.emplace_back(hardware_interface::StateInterface(
    joint_names_[i], "status",            &status_states_[i]));
